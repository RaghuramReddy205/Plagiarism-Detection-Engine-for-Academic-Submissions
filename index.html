⚙ Detection Algorithms

Main.java DSA-3 Architecture

1. Text Preprocessing

Alphanumeric Filter

Normalizes input text by lowering case, removing punctuation, and collapsing whitespace to eliminate formatting evasion.

2. Rabin-Karp Rolling Hash

Dual Modulo (K=5)

Computes dual 64-bit polynomial hashes with BASE1=911382323, BASE2=972663749 over 5-gram token sequences with O(1) sliding transitions.

3. Winnowing Algorithm

Window W=4

Selects representative minimum hashes in sliding windows of size 4, bounding memory overhead while guaranteeing detection of duplicate matches.

4. Suffix Array & Kasai LCP

Prefix Doubling + O(N) LCP

Sorts suffixes lexicographically and computes Longest Common Prefix arrays using Kasai's algorithm to pinpoint maximal contiguous plagiarized substrings.
